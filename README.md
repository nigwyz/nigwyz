## 👨‍💻 About

I design and ship **AI systems that run on constrained hardware**: from training and optimizing models to deploying them on embedded devices and wiring them into reliable backends.

- 🔭 **Focus:** real-time computer vision, model optimization, and edge inference
- ⚙️ **Approach:** measure first (latency, memory, power), then optimize
- 🌱 **Currently:** building in public and sharing what I learn along the way
- 📫 **Reach me:** bellili.abdelaziz.10@gmail.com
